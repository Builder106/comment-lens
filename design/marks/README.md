# Marks

Both files were drawn with the Glaxnimate MCP server. Redraw them there and copy the path data into the components that inline them.

- `mark.svg`: the Comment Lens mark. A `//` comment marker whose second stroke has drifted out of step with the first, the way a comment drifts from the code beside it. Inlined in `components/landing/mark.tsx` and used for `app/icon.svg`.
- `squiggle.svg`: the reviewer's wavy underline drawn under a stale comment in the home page's history panel. Inlined in `components/landing/drift.tsx`.
